====================================================
평가 방식 설명
====================================================
- 검색 평가(Hit@K/Recall@K/MRR): LLM 미사용. 정답 조문 라벨과
  검색 결과 라벨을 문자열로 기계적 비교하는 객관적 지표.
- 답변 품질 평가: LLM-as-judge 방식. (질문, 검색된 근거 조문,
  생성된 답변)을 LLM에게 보여주고 4가지 기준으로 채점시킴.
- 리랭킹 폴백: rag/pipeline.py의 answer_question()이 1차 답변에서
  "NOT_RELEVANT" 판정을 받은 경우에만, rag/retriever.py의 hybrid_search를
  candidate_k=30으로 넓게 다시 돌리고 rag/reranker.py의 cross-encoder로
  재정렬해 top_k를 재선정, 답변을 한 번 더 생성한다.

실행 방법: uv run python eval/evaluate.py
